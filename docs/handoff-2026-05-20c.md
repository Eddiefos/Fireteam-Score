## Track 2 — Fireteam management

### New features

**Rename fireteam (owner only):** Pencil ✎ button appears next to the fireteam name. Tapping it swaps the name with an inline input + Save/Cancel. Enter key saves, Escape cancels. Optimistic state update.

**Kick member (owner only):** Each non-owner row in the new Members section shows a red "Kick" button. Tapping opens a confirm modal before removing.

**Leave fireteam (non-owner members):** A "Leave Fireteam" danger button at the bottom of the Members section for members who aren't the owner.

### Files changed

**`supabase/migrations/20260520000005_fireteam_management.sql`** — **PASTE INTO SUPABASE SQL EDITOR — NOT YET APPLIED**:
```sql
-- Allow fireteam creator to rename the fireteam
create policy "Creator can update fireteam name" on fireteams for update
  using (auth.uid() = created_by)
  with check (auth.uid() = created_by);

-- Allow fireteam creator to remove any member (kick)
create policy "Creator can remove members" on fireteam_members for delete
  using (
    exists (
      select 1 from fireteams
      where id = fireteam_members.fireteam_id and created_by = auth.uid()
    )
  );

-- Allow members to remove themselves (leave)
create policy "Members can leave fireteam" on fireteam_members for delete
  using (user_id = auth.uid());
```
