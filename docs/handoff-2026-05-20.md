## New features

### Live hole tracking
**Problem:** The resume card on HomeScreen always showed "Hole 1 of 9" regardless of progress.

**Fix:** After each score is confirmed via Supabase realtime, `LiveScorecardScreen` recomputes how many holes have all players scored and calls `updateHolesPlayed(roundId, count)`. Uses a ref to avoid redundant DB writes.

- New function: `src/services/rounds.ts → updateHolesPlayed(roundId, holesPlayed)`
- Effect in `src/screens/LiveScorecardScreen.jsx` (after the `round` useMemo — order matters, was a bug)

### Realtime player list
**Problem:** If the host added a player after Player B was already on the Live Scorecard, Player B wouldn't see them without reloading.

**Fix:** `useRoundPlayers` now subscribes to `postgres_changes INSERT` on `round_players` filtered to `round_id=eq.{roundId}`. New players are pushed directly into state, deduplicated by `id`.

- Modified: `src/hooks/useRoundPlayers.ts`
- Test mock updated: `src/hooks/__tests__/useRoundPlayers.test.ts` (uses `vi.hoisted` for channel mock)

### Avatar / colour / initials in Settings
**Problem:** All users looked identical — same orange colour, auto-generated initials from email, no way to change either.

**Fix:** `SettingsScreen` fully rebuilt. Now shows:
- Live avatar preview that updates as you type
- Name input (pre-filled from profile)
- Initials input — auto-derived from name (first letter of each word), but manually editable; once touched, stops auto-updating
- 6 colour swatches from `PLAYER_COLORS` with selection ring
- Save calls `updateProfile({ display_name, initials, avatar_color })`

`SettingsScreen` now takes `userId` instead of `user`/`onSave` — fetches its own profile via `useProfile(userId)`.

- Modified: `src/screens/AuthScreens.jsx`
- Modified: `src/App.jsx` (passes `userId` instead of `user`/`onSave`)

### Account page shows real avatar
**Problem:** AccountScreen hardcoded initials from the auth email and always used forest green — didn't reflect actual profile data.

**Fix:** `AccountScreen` now takes `go` and `userId` props, calls `useProfile(userId)`, and renders the real `Avatar` component with correct colour and initials. Added an "Edit profile ›" row that navigates to Settings.

- Modified: `src/screens/AuthScreens.jsx`
- Modified: `src/App.jsx`

### Round deletion
**Problem:** The trash icon in `RoundDetailScreen` called `abandonRound` (set status to `'abandoned'`) — rounds stayed in history forever.

**Fix:** New `deleteRound(roundId)` service function does a hard DELETE with `{ count: 'exact' }` and throws if 0 rows affected (RLS block detection pattern). Scores and round_players cascade automatically.

- New function: `src/services/rounds.ts → deleteRound(roundId)`
- Modified: `src/screens/RoundDetailScreen.jsx` (imports and calls `deleteRound`)
- New migration: `supabase/migrations/20260520000000_round_delete_policy.sql`

**Required SQL** (already applied to production manually):
```sql
drop policy if exists "Round creator can delete" on rounds;
create policy "Round creator can delete" on rounds
  for delete using (auth.uid() = created_by);
```

### HomeScreen vs-par chips
**Problem:** Recent round cards on HomeScreen showed only course name and date — no indication of how you played.

**Fix:** HomeScreen now calls `usePlayerRounds(userId)` and builds a `roundId → vs-par` lookup map. Each recent round card shows a `ParChip` (e.g. `+3`, `−1`, `E`) once the data loads. Non-blocking — cards render immediately, chip appears shortly after.

- Modified: `src/screens/HomeScreen.jsx`

## Bug fixes

### TDZ crash on LiveScorecardScreen
`holesCompleted` useMemo referenced `round` before `round` was declared — JavaScript temporal dead zone error, blank screen on load. Fixed by moving the memo to after the `round` definition.

### Course creation returned to wrong screen
Creating a course from `StartRoundScreen` redirected to `CoursesScreen` after save. Fixed with a `returnTo` param: `StartRoundScreen` passes `go('newCourse', { returnTo: 'start' })`, and `NewCourseScreen` uses `params.returnTo || 'courses'` for both save and back navigation.

- Modified: `src/screens/StartRoundScreen.jsx`
- Modified: `src/screens/CoursesScreen.jsx`
